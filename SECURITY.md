# Security Policy

## Reporting a vulnerability

Do not disclose suspected vulnerabilities in a public issue. Use GitHub's
private vulnerability reporting for `spideyanik/aegisscope` and include:

- affected version or commit
- impact and prerequisites
- minimal reproduction steps
- suggested remediation, if known

Do not include credentials, access tokens, private assessment reports, or data
from systems you do not own.

## Assessment authorization

AegisScope is intended only for systems covered by current written
authorization. A security report about AegisScope does not authorize testing
third-party systems with the tool.
